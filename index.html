⚙️ Prepara tu sesión

Separa las palabras con comas o escribe una por línea. Puedes incluir nombres propios.
Si no añades dibujos, el programa intentará elegir uno automáticamente.
La lista integrada contiene palabras habituales con dibujos tipo emoji. Puedes repetir sesiones para practicar otras palabras.

🎙️ El micrófono se solicita al pulsar «Decir palabra» por primera vez y se mantiene preparado mientras esta página esté abierta. Funciona mejor en Chrome o Edge actualizado desde localhost o HTTPS. El navegador puede interpretar mal alguna pronunciación.

Incluye al menos 3 palabras distintas para crear opciones variadas.
